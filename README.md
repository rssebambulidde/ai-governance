# SamaBrains AI governance solutions

This repository documents AI governance and security capabilities built **at and for [SamaBrains](https://samabrains.com/)**: an independent practice in Uganda that reviews how organisations govern, secure, and use AI.

AI governance information at SamaBrains did not live in one place. Practice pages, blog posts, and public frameworks sat in different tools and formats. Staff preparing a review or a client reply had to search by hand. Customers asking what SamaBrains does, or what a named framework requires, could not get an instant, cited answer from the same corpus. This repo holds the solutions that close that gap.
